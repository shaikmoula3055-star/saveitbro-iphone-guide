Where to find downloaded Instagram videos on iPhone

If you downloaded an Instagram video in Safari, start in the Files app. You can then move a compatible video to Photos if you want it in your library.

Find the file in Safari or Files

  1. In Safari, tap the Downloads button near the address bar if it appears, then tap the file to open it.
  2. In the Files app, tap Browse, then check iCloud Drive → Downloads and On My iPhone → Downloads. If you set a custom download folder, check there.
  3. To confirm the folder, open Settings → Apps → Safari → Downloads. On older iOS versions, Safari may appear directly in Settings.

Save the video to Photos

Open the video in Files, tap Share, then choose Save Video if it appears. Open Photos to verify that the video plays. The original file stays in Files until you remove it.

If the video is missing or won’t save

  • Check that the browser completed the download. If the video simply opened in a tab, use the download control and confirm the file appears in Files.
  • If Save Video is missing, try playing the file in Files. A file that cannot play may be incomplete or in a format Photos does not support.
  • Check available iPhone storage if the download or save repeatedly stops.
